현장 실측 입력 (상단 3열 하부)

규격 / 옵션 카드 바로 아래에 배치되며, 상단 행에 D_min (OD, mm)(좌) · D_max (OD, mm)(우) 절대치 입력란, 하단 행에 기준 D 대비 −편차 / +편차 (mm) 입력란(id: i-devmin, i-devmax)이 제공됩니다. 두 행은 양방향으로 자동 동기화되므로 편차 칸에 예컨대 -2, +2를 입력하면 D=8,000mm 기준 D_min=7,998mm, D_max=8,002mm가 즉시 계산되며, 반대로 절대치 입력 시 편차가 자동 산출됩니다. D_max < D_min 역전 시 오류 경고를 즉시 표시하고, 정상 입력 시 예측 진원도 → 현장 실측 카드·단면도(초록 일점쇄선)·규격 판정 탭에 실시간 반영됩니다.

D_min = D + ΔD_min · D_max = D + ΔD_max기준 직경 D 대비 −/+ 편차 입력과 절대 외경 간 양방향 자동 동기화
Ovality (%) = (D_max − D_min) / D_nominal × 100동일 단면 외경(OD) 실측 기반 진원도 (D_max ≥ D_min 필수)

롤러 세트 최적화 — 구조 기준 스팬 · 지지 성능

✓ 핵심 원칙 & 하단 배치

하단 요약 행 1열 최소 권장 롤러 세트 바로 오른쪽(2열)에 롤러 지지 성능 분석(접촉각 · 롤러당 하중 · 접촉 응력 · 국부 변형 및 ∑Fy=W 평형 잔차)이 배치됩니다. 대경관은 플레이트 폭(≈2m)으로 Girth Weld 간격이 짧더라도 완료 용접부는 일체화 단면이므로 세트 수에 영향을 주지 않고, 구조 기준과 진행 중인 용접 수로만 결정됩니다.

7-3. 최종 결정 공식

구조 기준 (처짐 · Hertz · L/D · 스팬≤2.5D)
n_struct = max(n_defl, n_hertz, n_LD, n_span, 2)완료된 Girth Weld 수 포함하지 않음

⚠ 용접 진행 중 최소 4세트가 필요한 이유 · 단관/단척 예외

용접부는 통상 파이프 중앙 부근에 위치합니다. 4세트 배치 시 용접부 좌우에 각 2세트가 위치해 ① 회전 안정성 ② Fit-up 갭·개선각도 균일 유지 ③ 열변형 편심 안정화가 확보됩니다. 단, Girth Weld 총수가 0인 단관이거나 길이 L이 짧은 단척 파이프(L < 4·minPitch, 예: L=1,000mm)에서는 활성 용접 4세트 규칙이 적용되지 않으며 물리적 배치 한계(2세트)가 우선 적용됩니다.

핵심 계산 공식

기본 변수

D_mean = D − t평균 직경 (mm)
R = (D − t) / 2평균 반경 (mm)
A = π(D² − ID²) / 4단면적 (mm²)
w = γ × A단위 길이당 자중 (N/mm) · γ = 7.85×10⁻⁵ N/mm³
I_ring = t³ / 12링 단위 폭 관성모멘트 (mm⁴/mm) — 전 지지상태 링 해석 공통
I_beam = π(D⁴ − ID⁴) / 64원형 단면 2차 모멘트 (mm⁴) — 단순보 축방향 처짐 계산용

자연상태 — Roark Ring

dDv = −0.1488 · w · R³ / (E·I_ring)수직경 변화량 (mm)
dDh = +0.1369 · w · R³ / (E·I_ring)수평경 변화량 (mm)
oval = 0.2857 · w · R³ / (E·I_ring)전방위 진원도 = D_max − D_min (반링 자중 적분으로 바닥 반력 R_base = 2V_B 독립 검증)

120° 새들 — 균일 반경방향 접촉압 (2α = 120°)

oval_saddle ≈ oval_natural × 0.4956접촉호 2α=120° 반경방향 분포압을 링 Green 함수로 직접 적분

터닝롤러 — Castigliano · 전방위 링 적분 (N=2,000, 0.5° 격자 + 황금분할 탐색)

반경방향 법선 반력 & 대칭 피벗 보기 가정 (∑Fy = W)
TR2: N = W / (2·cosα)단일 롤러 반경방향 법선 반력 (수직성분 N·cosα = W/2)
Double Roller: N₁ = N₂ = W / [4·cos(α_c)·cos(γ)]등간격 대칭 피벗 보기(L₁=L₂) 가정 시 내·외측 롤러 등분배 (∑Fy = W)
부정정 (M_A, N_A) 동시 해법 & 전방위 진원도
∫₀ᵖ M(φ)dφ = 0 · ∫₀ᵖ M(φ)·(1−cosφ)dφ = 0상부 단면 휨모멘트 M_A·축력 N_A 연립 해석
D(θ) = D + ΔD(θ)θ ∈ [0°, 90°] 0.5° 격자(181점) + 황금분할 극값 보정(tol = 10⁻⁴ rad)
oval = max D(θ) − min D(θ)수직·수평뿐 아니라 45° 대각 타원화까지 포착
수치 최적화 검증: α_opt = 45.0° ★argmin_α [D_max(α)−D_min(α)] = 45.0° (m=2 상쇄, 전방위 ≈ 자연의 5.68%)

Hertz 접촉 응력 (선접촉 · 세트 분담 길이 반영)

α = arcsin(C-C / (D + rd))강관 외경(D)과 롤러 외경(rd) 중심거리 기반 지지각
F = N_per_mm × (L / n_sets)롤러 1개 부담 하중 (세트당 분담 길이 L_trib = L / n_sets)
R_eff = Rp·Rr / (Rp + Rr)유효 접촉 반경
1 / E_eff = (1−ν_p²)/E_p + (1−ν_r²)/E_r일반 유효 탄성 계수 (Steel / Urethane / Rubber 반영)
b = √(4·F·R_eff / π·cl·E_eff)접촉 반폭 (mm)
P_max = 2·F / (π·cl·b)최대 접촉 응력 — Steel 기준 안정 < 600 MPa (D≥6000 또는 >500MPa 우레탄 권장)

롤러 세트 최적화 (구조 기준 스팬)

구조 기준 허용 스팬
δ_allow = 0.0005 · D허용 처짐 (0.05%D)
L_defl = ⁴√(384·E·I_beam·δ_allow / 5·w)처짐 기준 허용 스팬
span_hz = [600²·π·cl·R_eff / (E_eff·w)] × 2·cos45°Hertz 기준 허용 스팬 (세트당 2롤러 반경방향 하중, P = 600 MPa)
세트 수 결정
n_struct = max(n_defl, n_hertz, n_LD, n_span, 2)구조 기준 (완료 Girth Weld 미포함)
n_active = min(max(effNA + 3, 4), n_max_phys)유효 진행 용접 effNA = min(active, nW) > 0 시 (단척 물리 상한 적용)
n_rec = max(n_struct, n_active, n_overhang, 2)최종 권장 세트 수
span = L / (n_rec + 1)   [mm]균등 배치 간격
